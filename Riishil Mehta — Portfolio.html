What I've built

    
Three projects I can talk through in depth — what the problem actually was, what I built, and where it stands now.


    

      

        
Yama AI

        ongoing
      

      
Founder & full-stack developer

      

        
problem
I wanted one assistant that could solve a physics problem, read a PDF, check the weather and write code — without stitching together five separate tools, and without renting someone else's model.

        
build
A Python/FastAPI backend that does the reasoning itself: SymPy/ChemPy for step-by-step math and chemistry, Tesseract for OCR, document parsing for PDF/DOCX/XLSX, Web Speech API for voice in and out, plus live weather, news, stocks and GitHub lookups.

        
now
Live and in daily use. Recent work has gone into search quality (trusted-domain ranking, verifying sources are actually reachable before citing them) and fixing a deploy pipeline broken by a numpy/Python version mismatch.

      

      
Python · FastAPI · SymPy · Tesseract OCR · TinyDB/SQLite

EDUTrack Pro + Smart NFC ID Card

        pitching schools
      

      
Founder, AirNix

      

        
problem
Schools run on paper syllabi and ID cards that do nothing. Parents have no way to see what their kid is actually being taught.

        
build
A management system with separate admin, teacher, student and accountant panels, tied to an NFC smart ID card so a parent can tap in and see uploaded class material from home.

        
now
Pitched to MSB Institute with a worked-out per-card pricing model (~₹188/card/year including print, software and maintenance). Current build priority is moving uploaded files off single-device storage onto Firestore so they sync across devices.

      

      
JavaScript · Firebase/Firestore · NFC · GitHub Pages

16-bit x86 Operating System

        boots in QEMU
      

      
Sole developer

      

        
problem
I wanted to actually understand what happens before an operating system exists — no framework, no abstraction underneath me.

        
build
A 512-byte MBR bootloader written in NASM, a disk I/O layer using raw BIOS interrupts, and a kernel loaded at address 0x1000 — with build scripts for both Linux/macOS and Windows.

        
now
Boots cleanly in QEMU. Next decision point is whether to add an interrupt-driven keyboard driver or move to 32-bit protected mode.

      

      
NASM · x86 assembly · BIOS interrupts
